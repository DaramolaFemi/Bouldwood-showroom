Curated assets folder

This folder is for curated product imagery and locally stored assets.

To add local images:

1. Place images under this folder (e.g. `assets/products/sora-sofa-1.jpg`).
2. Update `src/data/products.ts` to point `images` to the local paths, e.g. `/assets/products/sora-sofa-1.jpg`.

Currently the demo uses stable placeholder images from `picsum.photos`.
