# Bouldwood

Bouldwood is a furniture showroom I built around a quiet, editorial shopping experience. The idea was to make the products feel considered without turning the site into a heavy ecommerce interface.

**Live site:** https://bouldwood-showroom.vercel.app/

## Built with

React, TypeScript, Vite and Motion.

## Run locally

Use Node 22.12+ or Node 24.

```sh
npm install
npm run dev
```

## What works

You can browse the collection, search and filter pieces, open product details, add items to the cart, save items for later, and switch between light and dark mode. The layout is responsive across desktop and mobile.

The cart and theme preference are stored in the browser.

## Demo note

This is a portfolio project, not a live furniture store. The checkout screen is only a review step. It does not collect card details or create real orders. Product names, prices and editorial photography are demo content.

## Checks

```sh
npm run typecheck
npm run build
npm test
```

Start the dev server before running the browser tests.
